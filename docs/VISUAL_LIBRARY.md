# KONBIT Visual Library — Futuristic Haitian Aesthetic

## What We Need
Images that blend **futuristic/sci-fi aesthetics** with **rich Haitian cultural DNA**. The visual language should feel like "Haiti in 2050" — a place where ancient Vodou wisdom, Caribbean colors, and cutting-edge technology exist together.

---

## Core Visual Elements

### Haitian Cultural Anchors
| Element | Description |
|---------|-------------|
| **Kreole palette** | Deep noir, sea blue, blood red, pineapple gold |
| **Vodou cosmology** | Loa symbols, ancestral spirits, sacred geometry |
| **Geography** | Citadelle Laferrière, Port-au-Prince skyline, Jacmel boardwalk, Labadie coast |
| **Architecture** | Gingerbread houses, French colonial ironwork, concrete mansions |
| **Food & Craft** | Haitian coffee, mangoes, cacao, woven textiles, drum circles |
| **Language** | Kreyòl text overlays, "Konekte. Tèt ansanm. Pou nou vanse." |

### Futuristic Wrappers
| Style | Look |
|-------|------|
| **Neon Vodou** | Sacred symbols glowing with neon outlines |
| **Afrofuturism** | Star maps, cosmic dreadlocks, spirit tech |
| **Solarpunk Haiti** | Solar panels on gingerbread roofs, green cities |
| **Holographic Heritage** | Ancient artifacts rendered in holographic light |
| **Cyber Rara** | Nighttime Rara festivals with LED headdresses and drone swarms |

## Negative Prompts

For any image generation, exclude:
```

ugly, low quality, blurry, text overlay (unless specified),
Western-centric architecture, generic African imagery
```

## Notes for the Bot

- Always start with "Haiti" or "Haitian" in the prompt so the model anchors the geography
- "Afrofuturism" is the single most effective style keyword — it signals the aesthetic instantly
- "Solarpunk" works better than just "futuristic" for the hopeful, green-tech direction
- Avoid generic "African" imagery — Haitian culture is distinct and should be specified
- Citadelle Laferrière is the most recognizable Haitian landmark — reference it when setting scene
- Kreyòl language text should be added in post (don't try to generate readable text in-image)
- Haitian coffee, mangoes, and cacao are great product anchors — always include when relevant
- The Rara festival is visually spectacular — reference nighttime Rara for cultural energy
